# Rappi Gabriella — látványterv

Prémium, egyoldalas látványterv: jóga · hangtálterápia · asztrozófiai elemzés.
Halásztelek / Budapest környéke — Himalájai Jóga Tradíció.

## Megnyitás

Nyisd meg az [index.html](index.html) fájlt böngészőben — az oldal önálló (a CSS és a JS be van ágyazva), nem igényel szervert vagy buildet.

Tipp: a bemutatóhoz add hozzá az URL-hez a `?motion=force` kapcsolót — így a rendszer „mozgás csökkentése" beállítása mellett is lejátszódik a teljes scroll-animáció.
